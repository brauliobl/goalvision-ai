# GoalVision AI

Plataforma de análise desportiva com foco em clareza, transparência e várias modalidades.

## Primeira versão
- Página inicial responsiva em português.
- Secções para futebol, basquetebol, ténis e voleibol.
- Pesquisa e filtros de modalidades.
- Interface demonstrativa preparada para receber dados desportivos verificáveis.
- Avisos claros: exemplos visuais não são previsões nem dados ao vivo.

## Executar localmente
```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Próximas etapas
1. Ligar uma fonte fiável de calendários e resultados.
2. Criar o motor de análise com probabilidades explicáveis.
3. Adicionar contas, histórico e preferências.
4. Testar em telemóveis antes do lançamento.

**Importante:** probabilidades são estimativas, nunca garantias de resultado.
